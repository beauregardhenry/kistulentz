KISTULENTZ FOR MAC
Published by Beau Henry

SYSTEM REQUIREMENTS
- macOS Sequoia 15 or later
- Apple silicon or Intel Mac

INSTALL
1. Drag Kistulentz into the Applications folder.
2. Open Kistulentz from Applications.

FIRST-OPEN SECURITY MESSAGE
Beau Henry does not yet have an Apple Developer account, so Apple cannot verify
the publisher automatically. macOS may prevent the first launch even though the
app has been packaged without modifying your Mac's security settings.

If macOS blocks the app:
1. Try to open Kistulentz once and dismiss the warning.
2. Open System Settings.
3. Select Privacy & Security.
4. Scroll to the Security section and click Open Anyway beside Kistulentz.
5. Enter your Mac password and confirm Open.

Do not disable Gatekeeper or run Terminal commands. After the one-time approval,
Kistulentz will open normally.

PRIVACY
Kistulentz analyzes readability and EPUB reference books locally. The EPUB can
guide style, vocabulary, tone, character, continuity, voice, and tempo even
without an API key.

The Reference Library is stored in a folder you choose. It contains Markdown
profiles, short attributed excerpts, combined author and genre profiles, and a
hidden index used to reopen large libraries quickly. Folder and EPUB imports do
not contact OpenAI or Anthropic.

Kistulentz contacts OpenAI or Anthropic only when you choose Polish or Deepen w/
AI. It then sends the relevant Markdown, a local reference profile, and selected
short EPUB excerpts to the provider you selected. It does not upload complete
EPUB files or the complete Reference Library. API keys are stored in the Mac
Keychain.

DRM-protected or image-only EPUB files cannot be analyzed because they do not
provide readable book text.
