KISTULETZ FOR MAC
Published by Beau Henry

SYSTEM REQUIREMENTS
- macOS Sequoia 15 or later
- Apple silicon or Intel Mac

INSTALL
1. Drag Kistuletz into the Applications folder.
2. Open Kistuletz from Applications.

FIRST-OPEN SECURITY MESSAGE
Beau Henry does not yet have an Apple Developer account, so Apple cannot verify
the publisher automatically. macOS may prevent the first launch even though the
app has been packaged without modifying your Mac's security settings.

If macOS blocks the app:
1. Try to open Kistuletz once and dismiss the warning.
2. Open System Settings.
3. Select Privacy & Security.
4. Scroll to the Security section and click Open Anyway beside Kistuletz.
5. Enter your Mac password and confirm Open.

Do not disable Gatekeeper or run Terminal commands. After the one-time approval,
Kistuletz will open normally.

PRIVACY
Kistuletz analyzes readability and EPUB reference books locally. The EPUB can
guide style, vocabulary, tone, character, continuity, voice, and tempo even
without an API key.

Kistuletz contacts OpenAI or Anthropic only when you choose Polish. It then sends
the current Markdown, a local reference profile, and selected relevant EPUB
excerpts to the provider you selected. It does not upload the complete EPUB.
API keys are stored in the Mac Keychain.

DRM-protected or image-only EPUB files cannot be analyzed because they do not
provide readable book text.
