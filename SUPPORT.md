# Kistulentz Support

Use the repository's GitHub Issues page for installation help, bug reports, and feature requests.

For a useful bug report, include:

- Kistulentz version
- macOS version
- Apple silicon or Intel Mac
- What you expected and what happened
- Short, repeatable steps using nonprivate sample text
- The exact error message, if one appeared

Never post API keys, unpublished manuscripts, copyrighted EPUB files, project backups, private research, or other confidential material.

If a project cannot open and Kistulentz offers recovery, choose a last-known-good or pre-migration snapshot in the recovery window. Recovery first preserves the current project metadata and does not replace manuscript Markdown files.
